Modules

Reverse Cipher

Encrypts text by reversing its characters, with decryption achieved by reversing it back.

Caeser Cipher

Cipher that shifts letters a fixed number of places in the alphabet to encrypt and decrypt text.

Fence Cipher

Encrypts text by writing it in a zigzag pattern across multiple rows..

Subsitution Cipher

Cipher encrypts text by replacing each letter with another letter according to a fixed system.

Transposition Cipher

A Transposition cipher encrypts text by rearranging its characters according to a specific system.

Pigpen Cipher

A Pigpen cipher encrypts text using a geometric grid or symbol system to represent each letter.
